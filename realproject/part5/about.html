About SleeveNotes

This application was developed as the final project for CSCE 242. It serves as a digital catalog for vinyl record enthusiasts to manage and track their personal collections.

The project showcases skills in web design using HTML and CSS, leveraging Flexbox for layout and CSS Variables for theming. It also includes interactivity powered by JavaScript to enhance the user experience on mobile devices.
